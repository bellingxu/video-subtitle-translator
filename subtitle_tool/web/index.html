设置

写上剧名、主要人物的名字、性别和关系，翻译会更准、人名更统一。提示是跟着“视频文件夹”走的，换一个文件夹（另一部剧）可以另写一份。改了以后，重新处理的视频会重新翻译。
省电安静：用 Mac 自带的硬件编码芯片，几乎不占 CPU，电脑不烫、风扇不吵；画质一样，文件大约大四成（15 分钟的标清视频约 225 MB）。
文件更小：用软件编码，文件最小（约 160 MB），但 CPU 会跑满，风扇会响。两种速度差不多。
默认的 flash 又快又便宜，日常足够；pro 更贵一些，翻译更讲究。
